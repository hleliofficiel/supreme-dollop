Application Architectural Summary

Nova Musique is a flagship Android offline music suite engineered with modern Kotlin and Jetpack Compose. It includes advanced audio processing, offline storage in[...]

Module / Layer Technology Stack Key Responsibilities
UI Framework Jetpack Compose + Material 3 Edge-to-edge screens, dynamic themes, responsive layouts, animated visualizers
Playback Engine AndroidX Media3 ExoPlayer Background audio service, notification media controls, audio session management
Database Layer Room Database (SQLite) + KSP Favorites storage, custom playlists, listening history, smart playlists
Audio DSP & EQ Android Equalizer & BassBoost API 5-band equalizer curve, 3D spatializer, bass boost, reverb presets
Lyrics Engine Retrofit + LrcLib API + LrcParser Online LRC lyrics search, timestamp parsing, real-time karaoke scrolling
Monetization Google Mobile Ads SDK (AdMob) Banner ads, interstitial transitions on song change, fallback test ad keys
