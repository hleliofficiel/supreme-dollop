What is Nova Music?

Nova Music is a flagship, production-ready Android offline music player and audio processing application engineered using modern native Kotlin and Jetpack Compose (Material Design 3). Built on clean MVVM architecture, Nova Music delivers ultra-low-latency playback, full offline media indexing, synchronized LRC lyrics auto-fetching, a 10-band DSP equalizer, dynamic color theme engine, multi-language localization (including Arabic RTL), and Google AdMob monetization.

What You Receive

Full Android Studio Kotlin DSL project source code, Jetpack Compose layouts, Room database implementation, Media3 ExoPlayer service, LrcLib lyrics API integration, AdMob ad managers, 8 dynamic theme presets, documentation portal, and pre-compiled release APK.

Designed For

Commercial publishing on the Google Play Store, white-label client projects, custom audio player releases, reselling on app marketplaces, and turnkey mobile application development.

Customization Scope

Easily rename the app title, change launcher icons, set unique package ID (payfopus.novamusic.app), adjust dynamic color palettes, configure AdMob unit IDs, edit terms/privacy legal pages, and add localized language translations.

Quick Start Guide (7 Steps to Launch)

Follow this streamlined workflow to get Nova Music running in Android Studio and ready for release:

Step 1: Extract Source Package

Download and unzip the purchased project folder onto your local development machine.

Step 2: Open in Android Studio

Launch Android Studio (Ladybug 2026.1+ or newer) and select Open Existing Project pointing to the root workspace directory.

Step 3: Sync Gradle Dependencies

Allow Gradle (8.10+) to download dependencies and build project indexing automatically.

Step 4: Review Project Configuration

Verify package ID payfopus.novamusic.app in app/build.gradle.kts and inspect environment keys in .env.example.

Step 5: Configure Branding & AdMob

Update application title in strings.xml, replace adaptive launcher icons, and paste your AdMob Publisher/Unit IDs in configuration files.

Step 6: Build & Run Application

Connect a physical Android device or launch an Android Virtual Device (AVD) and click Run 'app'.

Step 7: Generate Release APK / AAB

Navigate to Build > Generate Signed Bundle / APK to produce production binaries for the Google Play Store.

Release History & Version Changelog

v1.1.0 — Official Rebranding & Performance Upgrade CURRENT RELEASE

Major release introducing brand alignment, dedicated application ID, audio engine optimizations, and documentation suite expansion.

  • Official Rebranding: Application rebranded from Nova Musique to Nova Music across Android strings, manifests, themes, and developer portal.

  • Duplicate Audio Finder utility with hash and metadata comparison.
  • Integrated AdMob monetization architecture for banner and interstitial ads.
