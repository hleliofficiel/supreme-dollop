Troubleshooting & Frequently Asked Questions

Fix common Android Studio compilation errors, Gradle version mismatches, and audio storage permission issues.

Common Build & Compilation Errors

Issue 1: "Unsupported class file major version 65" / Java SDK Error

Cause: Android Studio is set to an incompatible Gradle JDK version (e.g. Java 21 instead of JDK 17)[span_50](start_span)[span_50](end_span).

Fix: Go to Settings → Build Tools → Gradle → Gradle JDK and select JDK 17[span_51](start_span)[span_51](end_span). Then re-sync Gradle[span_52](start_span)[span_52](end_span).

Issue 2: Room Schema / KSP Generation Failures

Cause: KSP cache or Room database migration schema mismatch[span_53](start_span)[span_53](end_span).

Fix: Run clean build in Android Studio: Build → Clean Project, then Build → Rebuild Project[span_54](start_span)[span_54](end_span).

Issue 3: Missing .env File or Unresolved BuildConfig Symbols

Cause: .env file is missing from the project root directory[span_55](start_span)[span_55](end_span).

Fix: Copy .env.example to .env and re-sync Gradle files[span_56](start_span)[span_56](end_span).

Android Audio File Permissions

Android 13+ (API 33+) requires granular audio permissions instead of generic READ_EXTERNAL_STORAGE[span_57](start_span)[span_57](end_span):

app/src/main/AndroidManifest.xml 
<!-- Android 13+ Granular Audio Permission -->
<uses-permission android:name="android.permission.READ_MEDIA_AUDIO" />

<!-- Legacy Permission for Android 12 and lower -->
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE"
    android:maxSdkVersion="32" />

<!-- Foreground Service Permission for Media Playback -->
<uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_MEDIA_PLAYBACK" />

Frequently Asked Questions (FAQ)

Q1: Can I publish Nova Musique on Google Play Store?

Yes! Ensure you update the package name (applicationId), app launcher icon, and replace test AdMob IDs with your live production AdMob publisher keys[span_58](start_span)[span_58](end_span).

Q2: Does Nova Musique work offline without internet?

Yes. Core audio playback, 3D DSP equalizer, Room database indexing, and duplicate finder run 100% offline[span_59](start_span)[span_59](end_span). LrcLib lyrics search will fetch cached lyrics when connected[span_60](start_span)[span_60](end_span).
