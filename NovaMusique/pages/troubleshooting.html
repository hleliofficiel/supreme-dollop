❓ Troubleshooting & FAQ Guide

Solutions for common Gradle sync issues, JDK compatibility, missing media permissions, AdMob initialization, and release compilation.

Issue 1: Gradle Synchronization Failure

Possible Cause: JDK version mismatch or outdated Android Studio plugin.

Solution: Open File > Settings > Build, Execution, Deployment > Build Tools > Gradle and set Gradle JDK to JDK 17 or JDK 21. Then click Sync Project with Gradle Files.

Issue 2: Local Audio Files Not Appearing in Library

Possible Cause: Missing runtime READ_MEDIA_AUDIO permission or empty storage directory.

Solution: Ensure runtime storage permission is granted when launching the app. Copy audio tracks (.mp3, .flac) into the device's Music/ folder.

Issue 3: AdMob Ads Not Showing

Possible Cause: New AdMob accounts take 24-48 hours to activate production IDs, or invalid Ad App ID in manifest.

Solution: Test using Google's sample Test IDs first (ca-app-pub-3940256099942544/6300978111) to verify UI placement before switching to live unit IDs.

Frequently Asked Questions

Q: Can I publish Nova Music on the Google Play Store?

Yes. Nova Music is built explicitly for commercial publishing on Google Play. Be sure to change the package ID (payfopus.novamusic.app) and app title.

Q: Does Nova Music work offline without internet?

Yes! All core audio features, 10-band equalizer, playlists, and folder scanner work 100% offline. Internet access is only required for fetching LrcLib lyrics and serving AdMob ads.
