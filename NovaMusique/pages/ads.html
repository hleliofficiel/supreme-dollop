AdMob & Multi-Platform Ad Monetization Guide

Configure banner ads, interstitial song change transitions, and test unit IDs using AdManager and environment secrets.

AdMob Architecture Overview

Nova Musique includes an integrated AdMob monetization pipeline encapsulated inside com.example.util.AdManager.kt and rendered via AdBannerView.kt composables. Ads are disabled by default to keep local development clean, and can be activated instantly by toggling ADS_ENABLED="true" in .env.

Default Official Google Test Ad Units

If live production IDs are set to "none" or left empty, the app automatically falls back to official Google AdMob test keys:

AndroidManifest.xml AdMob Meta Data

Check or update your AdMob App ID inside app/src/main/AndroidManifest.xml:

app/src/main/AndroidManifest.xml 
<application>
    <!-- Google Mobile Ads App ID -->
    <meta-data
        android:name="com.google.android.gms.ads.APPLICATION_ID"
        android:value="ca-app-pub-3940256099942544~3347511713" />
</application>

Interstitial Ad Triggering Logic

In AdManager.kt, interstitial ads pre-load automatically and trigger every 4 song switches during playback:

com/example/util/AdManager.kt 
fun onSongChanged(activity: Activity?) {
    if (!isAdsEnabled) return
    songChangeCounter++
    // Triggers full screen interstitial ad every 4 track changes
    if (songChangeCounter % 4 == 0) {
        showInterstitial(activity)
    }
}
Publisher Policy Warning: Always test with official test ad units before releasing to Google Play. Never click live ads during testing to prevent AdMob account suspension.
