Restoration & Assembly Guide

Software prerequisites, Android Studio import instructions, Gradle synchronization, device testing, and production binary assembly.

System & Software Requirements

  • Android Studio: Ladybug (2026.1+) or newer
  • Java Development Kit (JDK): JDK 17 / JDK 21
  • Android SDK: API Level 36 (Android 16) target, API Level 24 (Android 7.0) minimum
  • Gradle: Gradle 8.10+ & Android Gradle Plugin 8.7+

Restoring Project in Android Studio

  1. Extract purchased source zip archive.
  2. Launch Android Studio and click Open.
  3. Select root project directory containing settings.gradle.kts.
  4. Wait for Gradle sync to complete automatically.

Building Binaries via Gradle CLI

Gradle CLI Commands 
# Assemble Debug APK for local testing
./gradlew assembleDebug

# Assemble Release APK
./gradlew assembleRelease

# Assemble Release Android App Bundle (.aab) for Google Play
./gradlew bundleRelease
