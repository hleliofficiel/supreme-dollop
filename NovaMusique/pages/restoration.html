System Requirements, Restoration & Assembly Guide

Complete beginner-friendly instructions to install prerequisites, import the codebase in Android Studio, assemble custom apps like Peaky Baby or Nova Musique, and generate APKs.

Latest 2026 Platform & Toolchain Support Guaranteed
Nova Musique is fully tested and optimized for the 2026 Android Development Ecosystem: Android Studio 2026.1+ (Ladybug / Meerkat / 2026.x), Android 16 (SDK API Level 36), Java JDK 17 & JDK 21, Gradle 8.10+, AGP 8.7+, KSP 2.0+, and Jetpack Compose 2026 Compiler.

1. System & Software Requirements for Beginners (2026 Standards)

Before compiling or modifying Nova Musique, ensure your computer satisfies these hardware and software specifications for the 2026 Android release:

2. Step-by-Step Android Studio 2026 Restoration

  1. 1. Launch Android Studio 2026 & Open Project

    Start Android Studio 2026.x, click Open, navigate to the extracted project folder containing settings.gradle.kts and app/build.gradle.kts, and click OK.

  2. 2. Set Gradle JDK to Java 17 or JDK 21

    Open File → Settings (or Android Studio → Settings on macOS) → Build, Execution, Deployment → Build Tools → Gradle. Under Gradle JDK, select JDK 17 or JDK 21 (Embedded JDK in Android Studio 2026).

  3. 3. Install Android 16 (API 36) SDK via SDK Manager

    In Android Studio 2026, click Tools → SDK Manager. Under SDK Platforms, check Android 16 (API Level 36) and click Apply to install missing SDK components automatically.

  4. 4. Create Environment File (.env)

    Duplicate .env.example at the project root and name it .env. The Secrets Gradle Plugin converts parameters in .env into static BuildConfig variables automatically during build.

    Terminal / Bash Command 
    cp .env.example .env
  5. 5. Sync Gradle Files & Resolve Dependencies

    Click the Sync Project with Gradle Files button (Elephant icon in top-right toolbar). Android Studio 2026 will fetch all dependencies (ExoPlayer, Jetpack Compose, Room, Retrofit, AdMob) and run KSP 2.0 code generation for Room database entities.

  6. 6. Run on Device or 2026 Emulator

    Connect a physical Android phone with USB Debugging enabled, or create an AVD (Android Virtual Device) running Android 16 in Device Manager. Select your device from the toolbar dropdown and click Run (Shift + F10).

3. App Assembly & Rebranding Guide (e.g., Peaky Baby App)

If you want to assemble a custom branded app (such as Peaky Baby or a custom version of Nova Musique), follow this exact step-by-step assembly process:

  1. Step A: Change App Launcher Label

    Edit app/src/main/res/values/strings.xml to set your desired app name:

    app/src/main/res/values/strings.xml 
    <resources>
    <!-- Change Nova Musique to Peaky Baby or your app name -->
    <string name="app_name">Peaky Baby</string>
</resources>

    Also update settings.gradle.kts at the project root:

    settings.gradle.kts 
    rootProject.name = "Peaky Baby"
  2. Step B: Change Package Name (Application ID)

    In app/build.gradle.kts, update applicationId under defaultConfig:

    app/build.gradle.kts 
    android {
    namespace = "com.example" // Keep namespace for generated R class compatibility
    defaultConfig {
        applicationId = "com.peakybaby.music.app" // Unique application ID
        versionCode = 1
        versionName = "1.0.0"
    }
}
  3. Step C: Assemble Debug APK

    To generate an instant testable APK for local testing:

    Terminal Command 
    gradle assembleDebug

    Output path: app/build/outputs/apk/debug/app-debug.apk

  4. Step D: Assemble Signed Production APK (NovaMusique.apk)

    To generate a optimized, signed release production APK:

    Terminal Command 
    gradle assembleRelease

    Copy the output APK to your documentation folder or distribution path as NovaMusique.apk!

Note on Environment Variables: Do not use or configure local.properties for API keys. All credentials (AdMob IDs, YouTube API, LrcLib base URL) are loaded from .env using standard Android Gradle Build Configuration.
