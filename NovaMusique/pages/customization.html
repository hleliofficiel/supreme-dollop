🎨 Customization & UI Branding Guide

Detailed customization instructions for App Name, Package Name, Launcher Icon, Theme Colors, Default Artwork, Localization, Legal Pages, and Versioning.

1. Application Title Customization

Update app/src/main/res/values/strings.xml:

<string name="app_name">Nova Music</string>

2. Package Name & Application ID

Update app/build.gradle.kts:

applicationId = "payfopus.novamusic.app"

3. Application Icon Customization

Icons are stored in app/src/main/res/mipmap-* and vector drawables in app/src/main/res/drawable/ic_launcher_*.

4. Theme Colors & Presets Customization

Edit color definitions in app/src/main/java/com/example/ui/theme/Color.kt and theme assignments in Theme.kt:

val LuxuryGoldPrimary = Color(0xFFF59E0B)
val NeonCyanPrimary = Color(0xFF00E5FF)
val CyberpunkPinkPrimary = Color(0xFFEC4899)

5. Default Artwork Fallback System

Vector artwork drawables (cover_concert.xml, cover_vinyl.xml, cover_piano.xml) ensure missing artwork never displays broken black images. Handled in SongArtworkImage.kt.

6. Localization Languages

Add or modify localized text constants in app/src/main/java/com/example/ui/i18n/StringResources.kt.

7. Legal Pages (Terms & Privacy)

Terms of Service and Privacy Policy content can be modified directly in app/src/main/java/com/example/ui/screens/LegalPagesScreen.kt.

8. Version Information

Increment build version code and name in app/build.gradle.kts:

versionCode = 2
versionName = "1.1.0"
