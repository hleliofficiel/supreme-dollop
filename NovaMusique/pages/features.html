Application Feature & Architecture Guide

Explore the core modules: Media3 ExoPlayer, Room Local Database, Pro 3D DSP Equalizer, LrcLib Synced Lyrics, and Duplicate Audio Finder.

1. Media3 ExoPlayer Engine (PlaybackManager.kt)

The playback engine is built on AndroidX Media3 ExoPlayer. It runs inside a Foreground Service (MusicService.kt) ensuring smooth continuous audio playback when the screen is locked or the app is minimized.

com/example/player/PlaybackManager.kt 
class PlaybackManager(private val context: Context) {
    val player: ExoPlayer = ExoPlayer.Builder(context).build()
    val currentSong = MutableStateFlow<Song?>(null)
    val isPlaying = MutableStateFlow(false)

    fun playSong(song: Song) {
        currentSong.value = song
        val mediaItem = MediaItem.fromUri(song.uri)
        player.setMediaItem(mediaItem)
        player.prepare()
        player.play()
        isPlaying.value = true
    }
}

2. Room Local Database (NovaDatabase.kt)

Nova Musique uses SQLite via Android Room to manage persistent user data including favorites, custom playlists, track play counts, and listening history.

Entity Class Database Table Description
SongEntity songs Stores track metadata, play counts, favorite flag, and file paths
PlaylistEntity playlists User-created playlist titles, created dates, and artwork tags
PlaylistSongCrossRef playlist_song_cross_ref Many-to-many relationship mapping songs into custom playlists

3. Pro Studio Suite (DSP Equalizer & Visualizers)

The Pro Studio Suite provides pro-grade audio controls:

  • 5-Band Equalizer: Direct hardware DSP tuning (60Hz, 230Hz, 910Hz, 3600Hz, 14000Hz).
  • 3D Spatializer & Bass Boost: Hardware virtualizer and bass enhancement controls.
  • Visualizer Studio Canvas: Custom Jetpack Compose Canvas rendering real-time frequency curves and spectrum bars.

4. Duplicate Audio Finder (DuplicateFinderScreen.kt)

Scans the device storage or local audio database to group audio files with identical titles, exact file sizes, or MD5 checksums, enabling users to perform one-tap storage cleanup.

5. Synced Lyrics Engine (LrcLib Integration)

Queries the LrcLib API using track title and artist name to retrieve LRC timestamped lyrics. The custom LrcParser.kt parses timestamps into milliseconds for synchronized auto-scrolling during playback.
