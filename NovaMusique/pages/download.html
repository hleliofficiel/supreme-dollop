Production APK Download & Assembly Guide

Download NovaMusique.apk directly or build production standalone APKs using Android Studio or Gradle CLI.

NovaMusique Production APK

Compiled standalone release APK ready for testing on physical Android smartphones and emulators.

Download NovaMusique.apk

1. Building Debug APK for Local Testing

To assemble a debug APK via command line or Android Studio terminal:

Terminal / Command Line 
# Linux / macOS / Windows Terminal
gradle assembleDebug

The compiled APK file will be generated at:

app/build/outputs/apk/debug/app-debug.apk

2. Building Signed Release APK & App Bundle (AAB)

To compile an optimized, minified production release APK or Google Play Android App Bundle (AAB):

Terminal / Command Line 
# Build Production Release APK
gradle assembleRelease

# Build Google Play App Bundle (AAB)
gradle bundleRelease

The compiled release artifacts will be saved at:

# APK Location
app/build/outputs/apk/release/app-release.apk

# AAB Bundle Location
app/build/outputs/bundle/release/app-release.aab

Keystore Signing Configuration

For production release builds, configure signing in app/build.gradle.kts using environmental variables or keystore file properties:

app/build.gradle.kts Signing Config Snippet 
android {
    signingConfigs {
        create("release") {
            storeFile = file("keystore/release.keystore")
            storePassword = System.getenv("KEYSTORE_PASSWORD") ?: "defaultPassword"
            keyAlias = System.getenv("KEY_ALIAS") ?: "novaAlias"
            keyPassword = System.getenv("KEY_PASSWORD") ?: "defaultPassword"
        }
    }
    buildTypes {
        getByName("release") {
            isMinifyEnabled = true
            proguardFiles(getDefaultProguardFile("proguard-android-optimize.txt"), "proguard-rules.pro")
            signingConfig = signingConfigs.getByName("release")
        }
    }
}
