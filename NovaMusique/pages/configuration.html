⚙️ App Configuration & Secrets Guide

Concrete step-by-step instructions for configuring application name, package ID, build versions, AdMob unit IDs, theme defaults, and release signing keys.

1. Application Title Configuration

  • 📍 Location: app/src/main/res/values/strings.xml
  • ❓ What to Change: Replace value of app_name string.
  • 🎯 Why: Controls launcher icon label on user home screen and system app manager.
  • Expected Result: Device launcher displays your custom brand title.
<string name="app_name">Nova Music</string>

2. Application Package ID & Versions

  • 📍 Location: app/build.gradle.kts
  • ❓ What to Change: Update applicationId, versionCode, and versionName.
  • 🎯 Why: Google Play requires a unique domain package identifier for app publishing.
  • Expected Result: Prevents package collision errors when uploading to Google Play Console.
android {
    namespace = "com.example"
    defaultConfig {
        applicationId = "payfopus.novamusic.app"
        minSdk = 24
        targetSdk = 36
        versionCode = 2
        versionName = "1.1.0"
    }
}

3. AdMob Unit Identifiers

  • 📍 Location: .env.example (copy to .env) and app/build.gradle.kts
  • ❓ What to Change: Replace sample AdMob IDs with production Google AdMob IDs.
  • 🎯 Why: Routes ad impressions and revenue directly to your Google AdMob account.
  • Expected Result: Live advertisements serve inside the app and generate revenue.
ADS_ENABLED="true"
ADMOB_APP_ID="ca-app-pub-3940256099942544~3347511713"
ADMOB_BANNER_ID="ca-app-pub-3940256099942544/6300978111"
ADMOB_INTERSTITIAL_ID="ca-app-pub-3940256099942544/1033173712"
