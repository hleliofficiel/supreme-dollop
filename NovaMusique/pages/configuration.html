App Configuration & Secrets Guide

Learn how to change the application ID, app title, launcher icon, and set up environment credentials in .env using Android Studio.

Changing Package Name (Application ID)

To publish your app or rename its unique store bundle ID, update the applicationId inside app/build.gradle.kts[span_7](start_span)[span_7](end_span). Keep namespace as com.example so existing Java/Kotlin imports and R class bindings remain intact without needing refactoring[span_8](start_span)[span_8](end_span).

app/build.gradle.kts 
android {
    namespace = "com.example" // Keep internal namespace
    defaultConfig {
        applicationId = "your.custom.domain.app" // Your unique bundle ID
        minSdk = 24
        targetSdk = 36
        versionCode = 1
        versionName = "1.0.0"
    }
}

Updating App Name Across Project Files

To ensure consistency between the Android home launcher, system settings, and build configuration, update the application name in these 3 places[span_9](start_span)[span_9](end_span):

  1. 1. Android Resource String (res/values/strings.xml)
    app/src/main/res/values/strings.xml 
    <resources>
    <string name="app_name">Nova Musique</string>
</resources>
  2. 2. Root Gradle Project Name (settings.gradle.kts)
    settings.gradle.kts 
    rootProject.name = "Nova Musique"
  3. 3. Project Descriptor Metadata (metadata.json)
    metadata.json 
    {
  "name": "Nova Musique",
  "description": "Flagship offline music player with 3D DSP Equalizer and synced lyrics"
}

Environment Credentials (.env)

Environment variables are configured in .env at the project root and automatically converted into BuildConfig static properties via the Secrets Gradle Plugin[span_10](start_span)[span_10](end_span).

.env Configuration Template 
APP_NAME="Nova Musique"
APP_VERSION_NAME="1.0.0"
APP_VERSION_CODE="1"
PACKAGE_NAME="payfopus.novamusique.app"

# YouTube API Key (for metadata enrichment)
YOUTUBE_API_KEY="AIzaSy..."
ENABLE_YOUTUBE_API="true"

# Monetization Configuration
ADS_ENABLED="true"
ADS_PROVIDER="AdMob"
ADMOB_APP_ID="ca-app-pub-3940256099942544~3347511713"
ADMOB_BANNER_ID="ca-app-pub-3940256099942544/6300978111"
ADMOB_INTERSTITIAL_ID="ca-app-pub-3940256099942544/1033173712"

App Launcher Icon Setup

The app uses Android Adaptive Icons defined in res/mipmap-anydpi-v26/ic_launcher.xml[span_11](start_span)[span_11](end_span). To change the app launcher icon[span_12](start_span)[span_12](end_span):

  • Replace foreground vector layer: app/src/main/res/drawable/ic_launcher_foreground.xml[span_13](start_span)[span_13](end_span)
  • Replace background color or vector layer: app/src/main/res/drawable/ic_launcher_background.xml[span_14](start_span)[span_14](end_span)
  • Recompile the project in Android Studio to update desktop and launcher icons[span_15](start_span)[span_15](end_span).
